# Machine Learning & Deep Learning Notebooks (ML-FILES)

A structured collection of machine learning algorithms, deep learning implementations, credit card classification projects, and NumPy numerical computing notebooks.

## Directory Structure

```
ML-FILES/
├── Credit-card-approval-prediction-classification-main/
│   └── Credit_Card_Approval_Prediction.ipynb
├── Deep Learning/
│   ├── ANN / CNN notebooks
│   └── Model training & loss curves
├── ML/
│   ├── Regression (Linear, Logistic)
│   ├── Classification (RandomForest, DecisionTree, SVM)
│   └── Clustering (K-Means)
└── NumPy/
    └── Array operations & mathematical computing notebooks
```

## Setup & Environment

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install requirements
pip install numpy pandas scikit-learn matplotlib jupyter
```
